# Nexora — Digital Agency Website

Nexora is a modern, high-performance digital experiences, technology, and creative agency website built with responsive design, dynamic micro-interactions, and integrated service estimators.

## 🚀 Live Demo
- **Production URL**: [https://nexora-agency-website.vercel.app](https://nexora-agency-website.vercel.app)

## ✨ Core Features
- **Design & Performance**: Built with Tailwind CSS, Kanit, Plus Jakarta Sans, and Space Grotesk typography.
- **Service Disciplines**: Web Development, Authorized Cybersecurity, Video Shooting & Production, Video Editing, and Creative Retouching.
- **Interactive Project Estimator**: Instant milestone calculation with scope breakdowns and direct inquiry generation.
- **Client-Side Routing**: SPA architecture with configured Vercel rewrites for seamless page reloads on all routes.

## 🛠️ Local Development & Preview
To run the local preview server:
- Double-click `Double-Click-To-Open.bat`, or
- Run PowerShell: `powershell -ExecutionPolicy Bypass -File server.ps1`

## 📦 Deployment
Deployed via Vercel:
```bash
npx vercel --prod
```
